# Contributing

Thank you for helping improve the project.

1. Open an issue before large behavioral or visual changes.
2. Keep the app dependency-light and compatible with the system Electron
   package.
3. Run `make check` before submitting a pull request.
4. Do not submit cookies, session data, QR codes, phone numbers, chat content,
   screenshots with personal data, or generated Electron profiles.
5. Keep remote content isolated: no Node.js integration, unrestricted
   navigation, permissive IPC, or broad permission grants.

By contributing, you agree that your contribution is licensed under the MIT
License.
